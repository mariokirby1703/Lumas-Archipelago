# Luma's Archipelago Integrations

A repository for Archipelago integrations of multiple of my favourite childhood games.

## Marbles! Balance Challenge

An Archipelago implementation for Marbles! Balance Challenge *(European / PAL Version)*. The current release does **NOT YET** include Marble Saga Kororinpa *(American / NTSC-U Version)*!

Read first: [Setup Guide](https://github.com/mariokirby1703/Lumas-Archipelago/blob/Marbles!-Balance-Challenge-AP/worlds/marbles_balance_challenge/docs/setup_en.md)

Then skim through the [Game Documentation](https://github.com/mariokirby1703/Lumas-Archipelago/blob/Marbles!-Balance-Challenge-AP/worlds/marbles_balance_challenge/docs/en_Marbles!%20Balance%20Challenge.md) for goals, locations, items, options, and notes about the current release.

Latest release: [GitHub Releases](https://github.com/mariokirby1703/Lumas-Archipelago/releases)

Source code: [worlds/marbles_balance_challenge](https://github.com/mariokirby1703/Lumas-Archipelago/tree/Marbles!-Balance-Challenge-AP/worlds/marbles_balance_challenge)

## Create

An Archipelago implementation for Create *(Wii, European / PAL Version, `SECP69`)*, using an external Dolphin client. Currently, only Save Slot 3 is supported.

Read first: [Setup Guide](https://github.com/mariokirby1703/Lumas-Archipelago/blob/Create-AP/worlds/create/docs/setup_en.md)

Then skim through the [Game Documentation](https://github.com/mariokirby1703/Lumas-Archipelago/blob/Create-AP/worlds/create/docs/en_Create.md) for goals, locations, items, options, and notes about the current release.

Latest release: [GitHub Releases](https://github.com/mariokirby1703/Lumas-Archipelago/releases)

Source code: [worlds/create](https://github.com/mariokirby1703/Lumas-Archipelago/tree/Create-AP/worlds/create)
