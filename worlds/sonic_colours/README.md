# Sonic Colours (Wii) for Archipelago

An Archipelago integration for the PAL Wii version of Sonic Colours (`SNCP8P`), using an external Dolphin client.

- [Game guide](https://github.com/mariokirby1703/Lumas-Archipelago/blob/Sonic-Colours-Wii-AP/worlds/sonic_colours/docs/sonic_colours.md)
- [Installation and setup](https://github.com/mariokirby1703/Lumas-Archipelago/blob/Sonic-Colours-Wii-AP/worlds/sonic_colours/docs/setup.md)
- [Default player YAML](https://github.com/mariokirby1703/Lumas-Archipelago/blob/Sonic-Colours-Wii-AP/worlds/sonic_colours/examples/SonicColours.yaml)

Requires Archipelago 0.6.7 or newer and an original PAL ISO. World access, Wisps and abilities are randomized, with optional rank checks, Game Land checks, music randomization and DeathLink. Opening your player patch creates a separate patched ISO and starts the client.
