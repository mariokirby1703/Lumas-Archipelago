# Create Setup Guide

## Required Software

- Archipelago 0.6.7 or newer
- Dolphin Emulator
- A PAL copy of Create, game ID `SECP69`
- The Create `.apworld` file

## Installing the APWorld

1. Install Archipelago.
2. Install `create.apworld` into Archipelago's `custom_worlds` folder.
3. Restart the Archipelago Launcher.
4. Open `Create Client` from the launcher.

If Archipelago asks to install missing Python requirements, allow it. The client needs Dolphin Memory Engine.

## How to Play

1. Start Create in Dolphin.
2. Play on Save Slot 3.
3. Open `Create Client`.
4. Connect to the Archipelago server with your slot name.
5. Once the client has connected to Dolphin and observed Save Slot 3, received World Access and Object items are enforced.

The first implementation is an external Dolphin RAM client. It does not patch the ISO and does not write vanilla Total Sparks.
