# Create for Archipelago

An Archipelago integration for the PAL Wii version of Create (`SECP69`), using an external Dolphin client.

- [Game guide](docs/en_Create.md)
- [Installation and setup](docs/setup_en.md)
- [Release notes](CHANGELOG.md)
- [Building and checking a release](docs/releasing.md)

Requires Archipelago 0.6.7 or newer and Save Slot 3. World access, objects, and Spark rewards are
randomized, with optional Create Chain checks and four additional II worlds.
