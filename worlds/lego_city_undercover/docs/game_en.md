# LEGO City Undercover

Target: 2017 Windows/Steam edition, App ID 578330, x64 DX11 executable LEGOLCUR_DX11.exe.
Current work confirms archive structures, internal objective IDs, scanner lock declarations and symbolic unlock actions.
No ability is presently proven randomizable, and no location is automatically sent to Archipelago.
Original game files are required only for developer research; an eventual world must not require assets at import time.

Story chapters, replayable Special Assignments and individual city objectives need separate persistent mappings.
Scanner entries include clues and script leftovers; their total is not a count of randomizer checks.
