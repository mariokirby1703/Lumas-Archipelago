# LEGO City Undercover

Experimental integration for LEGO City Undercover on Steam, Windows x64 DX11.
It provides catalogue generation, read-only game observations and partial AP
check detection. The debug goal uses City Completion Tokens; it is not a verified
native ending. Raw candidates include prerequisites and unbound collectibles.

The opt-in source client now includes native model/tool/cheat/currency delivery,
autosave requests, verification in the native save and post-check reward
suppression. New currency/suppression paths still need controlled in-game tests.
Story/area entrance gates, open-world initialization and full access logic remain
unfinished. Consult the setup tutorial and current native delivery status;
this is an experimental integration.
