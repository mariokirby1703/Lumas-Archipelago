# Compatibility

Only the supplied executable has been inventoried; its exact hash is in research/engine_analysis.md.
The diagnostic recognizes that hash for a read-only header test, not gameplay support.
Steam updates or modified executables must be independently researched before any write profile is enabled.

Mouse Support mod compatibility has not been tested. Its repository advertises native mouse/window features,
but proxy exports, hook implementation and interaction with an eventual bridge remain unverified.
Nintendo Easter Eggs and Special Saves compatibility has not been investigated far enough to make a support claim.
Neither is required, installed or redistributed. No DirectX hook, replacement DLL or archive patch was installed.

Fresh-save and existing-save behavior, achievements, co-op and Steam Cloud remain untested.
